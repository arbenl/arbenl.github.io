  • Hartimi i Specifikave (PRD): Aktorët e sistemit, funksionalitetet kyçe Must-Have dhe kontrolli i rreptë i Scope-it.

Arkitektura e Komponentëve & App Router (Next.js 15)

Server vs Client Components, routing i lëndshëm, dhe Skeleton Loaders.

▼
📘
Ligjërata
  • Diferenca mes React Server Components (RSC) dhe Client Components ('use client').

  • Përdorimi i layout.tsx, page.tsx, dhe loading.tsx.

Ushtrimi Laboratorik

  • Krijimi i gjendjeve të ngarkimit (Skeleton Loaders) që imitojnë aplikacionet native.
  • Ndarja e komponentëve interaktivë nga ata të pastër të renderimit të serverit.
🤖 GitHub Copilot Prompt
Write a Next.js 15 loading.tsx skeleton screen using Tailwind CSS pulse animation for a mobile product catalog list.

Baza e të Dhënave me Supabase (PostgreSQL & RLS)

Modelimi relacional për biznesin, migrimet SQL dhe Row Level Security.

▼
📘
Ligjërata
  • Modelimi i bazave të të dhënave për aplikacione tregtare dhe shërbime lokale.
  • Arkitektura e Supabase: PostgreSQL, PostgREST API dhe lidhja me Next.js.
  • Parimi i Row Level Security (RLS) - mbrojtja e të dhënave në nivel rreshti.
🧪
Ushtrimi Laboratorik
  • Krijimi i tabelave: categories, products, orders.
  • Shkrimi i policave RLS: Të gjithë mund të lexojnë produktet, vetëm pronari mund t'i modifikojë.
  • Lidhja e çelësave të mjedisit në .env.local dhe marrja e të dhënave të para.

Write a PostgreSQL SQL migration for Supabase to create a products table with id, name, price, image_url, created_at, and enable RLS with public read policy.

🎯 Rezultatet e të Nxënit (Learning Outcomes)

Në përfundim të kursit, studenti zotëron: (1) Ndërtimin e aplikacioneve mobile me Next.js 15 PWA; (2) Modelimin e bazave relacionale në Supabase me RLS; (3) Përdorimin e API-ve të pajisjes (Kamera, Gjeolokacion, Push); dhe (4) Përdorimin profesional të AI Pair Programming me GitHub Copilot.

🤖 Politika e Inteligjencës Artificiale (Copilot)

Përdorimi i GitHub Copilot është i lejuar dhe i rekomanduar si asistent programues. Megjithatë, studenti mban përgjegjësi absolute për kodin: në Demo Day, paaftësia për të shpjeguar logjikën e kodit rezulton në zbritje pikësh ose moskalim.
