Zbulo përgjigjen

2

Fjalori dhe burimet

UI (User Interface): ndërfaqja që sheh përdoruesi. State: gjendja. Optimistic update: ndryshim i përkohshëm para përgjigjes. Rollback: rikthimi pas gabimit.

MVP (Minimum Viable Product): produkti minimal i përdorshëm. API (Application Programming Interface): ndërfaqja për komunikimin mes pjesëve të aplikacionit.
