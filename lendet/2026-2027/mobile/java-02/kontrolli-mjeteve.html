Raporti yt

Rishikoje para dërgimit. Hapja e GitHub nuk e dërgon automatikisht: në GitHub duhet të shtypësh Create / Submit new issue. Raportet në repository-n e lëndës janë publike. Mos përfshi të dhëna private.

Hap raportin në GitHub

Nëse ke një raport, përditëso të njëjtin issue. Nëse GitHub nuk hapet, shkarkoje raportin dhe tregoja profesorit në ekran. Ruajtja e këtij raporti nuk të regjistron si të pranishëm; vijueshmëria ka QR të veçantë.

Nuk kam ende faqe në Vercel
  1. Shkarko faqen e vogël të provës. Hape me VS Code dhe ndrysho tekstin “Prova ime”. Ruaje dhe hape nga shfletuesi.
  2. Krijo një repository prove mobile-kontroll me README në GitHub. Ngarko skedarin index.html me Add file → Upload files dhe ruaje.
  3. Në Vercel hap Add New → Project dhe importo këtë repository. Nëse kërkohet Framework Preset, zgjidh Other. Faqja është HTML statike, pa komandë build. Lejo qasje vetëm te repository që do të importosh.
  4. Pas Deploy, hap URL-në e publikuar dhe verifiko tekstin që ndryshove. Hape edhe nga telefoni. Vetëm atëherë shëno se publikimi punon.

Nëse ky hap ngec, raporto “Ka problem” dhe vazhdo me skicën në letër. Profesori të ndihmon gjatë bllokut të instalimeve.

Instalimet zyrtare: Git, Node.js 24 LTS me npm, VS Code. Pas instalimit rihap terminalin. Në Windows mund të përdorësh Command Prompt nëse PowerShell pengon npm; kërko ndihmë pa ndryshuar vetë politikat e sigurisë.

Burime: kërkesat e Next.js dhe publikimi me Vercel. Ky kontroll përfshin mjetet e javës së dytë. Databazën dhe shërbimet e tjera i shtojmë kur duhen.
