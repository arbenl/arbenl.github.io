LIGJËRATA 3 · 05 / 14

Si e lexon Next.js këtë rrjedhë?

src/app/page.tsx                       → /
src/app/udhetimi/[id]/page.tsx         → /udhetimi/1
src/app/udhetimi/[id]/kerkesa/page.tsx → /udhetimi/1/kerkesa

App Router i Next.js i lidh dosjet me adresat. [id] ndryshon sipas udhëtimit.

LIGJËRATA 3 · 06 / 14

Faqe apo komponent?

Faqja

Ka adresën e vet. Për shembull lista në / ose detajet në /udhetimi/1.

Komponenti

Është pjesë e ripërdorshme e pamjes. Një KartaUdhetimi mund të shfaqet tri herë në listë.

LIGJËRATA 3 · 07 / 14

Një burim për tri karta

const udhetimet = [
  { id: "1", nisja: "Prishtinë", ora: "08:00", vende: 2 },
  { id: "2", nisja: "Fushë Kosovë", ora: "08:15", vende: 1 },
  { id: "3", nisja: "Lipjan", ora: "07:45", vende: 0 }
];

Fillojmë me të dhëna fiktive. Në Javën 4 do t’i lexojmë nga baza e të dhënave.

LIGJËRATA 3 · 08 / 14

Lidhja duhet ta ruajë zgjedhjen

<Link href={`/udhetimi/${udhetim.id}`}>
  Shiko detajet
</Link>

Kur Arta klikon kartën me ID 2, hapet /udhetimi/2. Adresa tregon çfarë zgjodhi.

LIGJËRATA 3 · 09 / 14

Si gjendet udhëtimi i zgjedhur?

const { id } = await params;
const udhetim = udhetimet.find((u) => u.id === id);

Faqja e detajeve lexon id nga adresa. Në versionet aktuale të Next.js, params pritet me await.

LIGJËRATA 3 · 10 / 14

Po nëse ID nuk ekziston?

Dikush hap /udhetimi/99.

Nuk shfaqim detajet e një udhëtimi tjetër. Thërrasim notFound() dhe përdoruesi sheh se kjo faqe nuk ekziston.

Një gabim i qartë është më i mirë se një përgjigje e gabuar.

LIGJËRATA 3 · 11 / 14

Çfarë do të thotë “Në pritje” sot?

Në ushtrimin e sotëm

Klikimi hap një ekran demonstrimi me tekst “Simulim: Në pritje”. Asgjë nuk i dërgohet shoferit.

Në aplikacionin e plotë

Kërkesa do të ruhet, shoferi do të përgjigjet dhe statusi do të përditësohet. Këto hapa vijnë më vonë.

LIGJËRATA 3 · 12 / 14

Prova e vogël në telefon

  • Lista lexohet pa lëvizje horizontale.
  • Prekja e kartës hap udhëtimin e duhur.
  • “Kthehu te lista” të kthen te zgjedhjet.
  • Adresa e pavlefshme jep përgjigje të qartë.
