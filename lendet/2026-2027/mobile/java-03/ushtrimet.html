Dy vende për punën tënde

Kodi është brenda aplikacionit Next.js. Raporti ruhet pranë README në repository. Shembull, nëse e nise me udhëzimin tonë:

rideshare-mobile/          ← repository yt personal
├── README.md
├── java-02.md
├── java-03.md             ← raporti i sotëm, jashtë aplikacioni/
└── aplikacioni/
    ├── package.json       ← terminalin e hap këtu
    └── src/
        ├── app/
        ├── components/
        └── lib/

Në VS Code (Visual Studio Code), hap dosjen e repository-t. Te Terminal → New Terminal shkruaj cd aplikacioni, pastaj npm run dev. Nëse package.json është në rrënjë, përdor vetëm npm run dev.

Repository do të thotë dosja e projektit në GitHub. Përdor të njëjtën llogari GitHub për repository-n dhe formularin e dorëzimit. Mos bëj Push te repository i profesorit.

Hapat e orës · 90 minuta

1. Hap projektin · 0–10 min

  1. Hap të njëjtin repository personal të Javës 2; mos krijo tjetër.
  2. Hap skicën dhe java-02.md. Krahasoji me demonstrimin e Javës 3.
  3. Nëse kodi është në aplikacioni/, hape terminalin aty. Në dosjen ku gjendet package.json nis npm run dev dhe hap adresën që jep terminali.
  4. Shkarko java-03.md tani; plotëso provat një nga një gjatë punës.

Kontrolli: faqja jote hapet në shfletues. Nëse projekti nuk niset, përdor udhëzimin e nisjes dhe kërko ndihmë tani.

2. Shfaq tri kartat · 10–35 min

  1. Krijo udhetimet.ts me tri udhëtime fiktive.
  2. Krijo KartaUdhetimi.tsx dhe përdore në page.tsx.
  3. Shto stilet për telefon.

Kontrolli: te adresa kryesore sheh saktësisht tri karta. Në Chrome/Edge: kliko me të djathtën → Inspect → ikonën e telefonit/tabletit; nuk duhet të ketë lëvizje anash. Shëno rezultatin te Prova 1 në raport.

3. Lidhi ekranet · 35–55 min

  1. Krijo faqen e detajeve. Kliko kartën e dytë: adresa bëhet /udhetimi/2 dhe shfaqet vendtakimi i saj.
  2. Krijo faqen e kërkesës. Kliko “Kërko vend”: duhet të lexosh Simulim: Në pritje.
  3. Hap kartën 3: “Nuk ka vende të lira” duhet të jetë i çaktivizuar. Shto faqen “Udhëtimi nuk u gjet” dhe provo adresën /udhetimi/99.

Kontrolli: mund të lëvizësh listë → detaje → kërkesë → mbrapa, pa rezervim real. Shëno rezultatet te Prova 2 dhe Prova 3.

4. Provo, shkruaj, ruaj · 55–70 min

  1. Me një koleg bëj tri provat: 1) lista në telefon; 2) detajet e kartës 2, zero vende dhe ID 99; 3) mesazhi “Në pritje” dhe kthimi mbrapa. Shëno edhe kur diçka nuk punon.
  2. Kontrollo që java-03.md ka nga një fjali për secilën provë dhe fshi të gjitha [PLOTËSO].
  3. Ruaje java-03.md pranë README, jashtë dosjes aplikacioni/. Skedari duhet të përfundojë me .md, jo .md.txt. Në GitHub Desktop zgjidh repository-n tënd. Te Summary shkruaj Java 3: kartat dhe faqet, pastaj Commit to main → Push origin. Kontrollo në faqen e repository-t që skedarët u shfaqën.

Kontrolli: repository yt online përmban kodin dhe raportin e sotëm.

5. Merr përgjigjen e GitHub-it · 70–90 min

  1. Hap formularin më poshtë. Zgjidh Java 3, vendos linkun kryesor të repository-t tënd publik (p.sh. https://github.com/llogaria-jote/rideshare-mobile) dhe kliko Submit. Ky krijon një dorëzim (Issue). Mos vendos linkun e localhost-it, Vercel-it ose të një skedari; këtu kërkohet linku kryesor i GitHub-it.
  2. Hap dorëzimin tënd dhe prit komentin Kontrolli automatik i dorëzimit, poshtë formularit. Ai shfaq 5 kontrolle, p.sh. 5/5 kontrolle teknike kaluan. Rifresko faqen nëse përgjigjja nuk shfaqet menjëherë; mos hap dorëzim të dytë.
  3. Nëse ka ❌, lexo skedarin që mungon, korrigjoje, bëj Commit → Push, pastaj komento vetëm rikontrollo te i njëjti dorëzim.

Përfundove kur: ke linkun e dorëzimit dhe e ke lexuar përgjigjen. Nëse GitHub ka vonesë, ruaj linkun dhe lajmëro profesorin; puna jote mbetet e dorëzuar.

Kodi i shembullit, një skedar në çdo hap

Për secilin skedar: krijo dosjet në VS Code → krijo skedarin → kopjo kodin → ruaj me Ctrl+S (ose ⌘S në Mac) → shiko shfletuesin. Ky është një model mësimor. Mund t’i ndryshosh emrat dhe vendet me të dhëna fiktive. Të gjitha rrugët më poshtë janë brenda aplikacionit: në shembullin tonë fillojnë me aplikacioni/src/. src do të thotë kodi burimor. Nëse projekti yt nuk përdor dosjen src, krijo skedarët përkatës në app, components dhe lib në rrënjë. Mos fshi layout.tsx: ai e mban strukturën e aplikacionit dhe e importon CSS-në. Shembulli përdor aliasin standard @/ të projektit të krijuar me udhëzimin tonë.

Hapi A · të dhënat e njëjta për të gjitha faqet

Krijo src/lib/udhetimet.ts. ID (identifier – identifikuesi) mbetet i njëjtë edhe kur ndryshon renditja e listës.

export type Udhetim = {
  id: string;
  nisja: string;
  destinacioni: string;
  ora: string;
  vendtakimi: string;
  vende: number;
};

export const udhetimet: Udhetim[] = [
  { id: "1", nisja: "Prishtinë", destinacioni: "AAB", ora: "08:00",
    vendtakimi: "Stacioni i autobusëve", vende: 2 },
  { id: "2", nisja: "Fushë Kosovë", destinacioni: "AAB", ora: "08:15",
    vendtakimi: "Te stacioni kryesor", vende: 1 },
  { id: "3", nisja: "Lipjan", destinacioni: "AAB", ora: "07:45",
    vendtakimi: "Qendra e qytetit", vende: 0 },
];

export function gjejUdhetimin(id: string) {
  return udhetimet.find((udhetim) => udhetim.id === id);
}

Hapi D · detajet e udhëtimit të zgjedhur

Krijo dosjet dhe skedarin src/app/udhetimi/[id]/page.tsx. Krijo dosjen udhetimi, brenda saj dosjen me emrin e saktë [id], pastaj skedarin page.tsx. Kllapat duhen shkruar. App Router lidh këto dosje me adresat e faqeve.

import Link from "next/link";
import { notFound } from "next/navigation";
import { gjejUdhetimin } from "@/lib/udhetimet";

export default async function Detajet({
  params,
}: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const udhetim = gjejUdhetimin(id);
  if (!udhetim) notFound();

  return (
    <main>
      <Link href="/">← Kthehu te lista</Link>
      <h1>{udhetim.nisja} – {udhetim.destinacioni}</h1>
      <p>Ora: {udhetim.ora}</p>
      <p>Vendtakimi: {udhetim.vendtakimi}</p>
      <p>Vende të lira: {udhetim.vende}</p>
      {udhetim.vende > 0 ? (
        <Link className="action" href={`/udhetimi/${id}/kerkesa`}>
          Kërko vend
        </Link>
      ) : <button className="action" disabled>Nuk ka vende të lira</button>}
    </main>
  );
}

Provo tani: kliko kartat 1 dhe 2. Hap kartën 3: veprimi është i çaktivizuar. Adresa me 99 shfaq 404; mesazhin dhe kthimin te lista i shton në hapin G.

Nëse ngec, kontrollo këto

“package.json nuk gjendet”
Je në dosjen e gabuar. Nëse ke aplikacioni/, shkruaj cd aplikacioni, pastaj npm run dev.
“Cannot find module @/…”
Kontrollo emrin dhe vendin e skedarit: src/lib/udhetimet.ts dhe src/components/KartaUdhetimi.tsx. Shkronjat e mëdha/vogla duhen të sakta.
Klikimi jep 404
Nëse është ID 1 ose 2, kontrollo dosjen udhetimi/[id]. Nëse është ID 99, ky është rezultati i pritur.
GitHub thotë se skedari mungon
Shiko repository-n online: a bëre Push? A është raporti pranë README? Korrigjo, bëj Push dhe komento rikontrollo te dorëzimi i parë.

Kufiri i Javës 3: kjo është një rrjedhë me të dhëna fiktive. Nuk ka rezervim, hyrje përdoruesi, databazë ose pagesë. Këto nuk kërkohen për dorëzimin e sotëm.
