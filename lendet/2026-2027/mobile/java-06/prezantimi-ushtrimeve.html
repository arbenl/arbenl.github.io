5 · Lexo përgjigjen para se të largohesh

GitHub kontrollon raportin, projektin, tri provat, skedarët PWA dhe emrat e skedarëve privatë.

Nëse mungon diçka: korrigjo → Commit → Push → komento rikontrollo në të njëjtin Issue.

A do të thotë 5/5 kontrolle teknike se aplikacioni mori automatikisht 3 pikë?

Jo. Bot-i lexon skedarët pa ekzekutuar kodin. Provat dhe cilësia vlerësohen sipas rubrikës; Java 6 ka deri në 3 pikë.
