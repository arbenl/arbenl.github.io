## Provat që bëra
### Prova 1: Hyrja, rifreskimi dhe dalja
[PLOTËSO] Hapa /panel pa hyrë, hyra me GitHub, rifreskova, pastaj dola.

### Prova 2: Shoferi ndryshon udhëtimin e vet
[PLOTËSO] Si shofer i ID 2 e ndryshova orën në 08:25.
Shkruaj çfarë u shfaq në panel, listë, detaje dhe SQL Editor. Rikthe 08:15.

### Prova 3: Veprimi pa leje refuzohet
[PLOTËSO] Nga formulari i hapur ndryshova ID në 1 dhe provova Ruaj.
Pastaj provova formularin e vjetër pasi roli u kthye udhetar dhe pas daljes.
Shkruaj mesazhet dhe a mbeti e pandryshuar ora në databazë.
