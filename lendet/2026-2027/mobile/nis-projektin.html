Nga dokumentet te aplikacioni

Përdor të njëjtin repository personal ku ke dorëzuar javët 1–2. Dokumentet mbeten në faqen kryesore.

1. Merre repository-n në kompjuter

  1. Hyr në GitHub Desktop me llogarinë tënde.
  2. Zgjidh File → Clone repository, repository-n tënd RideShare dhe një dosje lokale.
  3. Hape dosjen në VS Code. Në terminal kontrollo node --version. Duhet Node.js 20.9 ose më i ri; përdor versionin LTS.

2. Krijo aplikacionin vetëm një herë

Nëse repository yt ka tashmë package.json dhe një aplikacion Next.js që punon, vazhdo me të. Përndryshe, nga dosja e repository-t ekzekuto:

npx create-next-app@latest aplikacioni --ts --eslint --app --src-dir --use-npm

Prano zgjedhjet e rekomanduara. Kjo krijon kodin brenda aplikacioni/; nuk mbishkruan dokumentet e tua. Pastaj:

cd aplikacioni
npm run dev

Hap adresën lokale që shfaq terminali. Ndrysho titullin në src/app/page.tsx dhe shiko ndryshimin në shfletues.

3. Ruaje në GitHub

  1. Në GitHub Desktop kontrollo listën e ndryshimeve.
  2. Shkruaj një përmbledhje, p.sh. Nis RideShare, dhe kliko Commit to main, pastaj Push origin.
  3. Hape repository-n online dhe sigurohu që shfaqet kodi. Në javët tjera përsërit vetëm Commit + Push.

Mos ngarko node_modules, .next, .env ose fjalëkalime. Kontrollo që .gitignore i gjeneruar nga Next.js të mbetet në projekt.

Publikimi në Vercel

Importo repository-n personal. Nëse kodi është në aplikacioni/, zgjidh Root Directory: aplikacioni. Nëse kodi është pranë README, lëre rrënjën e repository-t. Variablat private vendosen te Environment Variables në Vercel, jo në GitHub.
