Java 4 · Demonstrim 12 minuta

Një ndryshim në Neon, dy ekrane të përditësuara

Mbaji hapur SQL Editor dhe aplikacionin Next.js të lidhur sipas ushtrimeve. Kjo faqe është rrjedha e demonstrimit; nuk lidhet vetë me databazën.

  1. 0–2 min: hape listën dhe kartën 2. Pyet klasën: “Nëse ndryshoj vetëm databazën, ku duhet të shihet ora e re?”
  2. 2–5 min: në SQL Editor ekzekuto UPDATE më poshtë. Rifresko listën dhe detajet e ID 2. Të dyja tregojnë 08:25.
  3. 5–7 min: pyet pse nuk u ndryshua asnjë komponent. Shpjego: i njëjti identifikues, i njëjti burim, dy pamje. Pastaj rikthe orën 08:15.
  4. 7–9 min: te lexoUdhetimet shto përkohësisht WHERE false. Rifresko: “Nuk ka udhëtime për momentin.” Hiqe kushtin dhe rifresko.
  5. 9–11 min: riemërto përkohësisht DATABASE_URL lokalisht pa e shfaqur sekretin në projektor; rinis serverin. Shfaq vetëm aplikacionin me mesazhin e gabimit. Rikthe konfigurimin dhe rinis.
  6. 11–12 min: pyet: “Në cilin rast morëm përgjigje nga databaza, por zero rreshta?” Jepua fjalën studentëve përpara përgjigjes.
UPDATE udhetimet SET ora = '08:25' WHERE id = '2';
-- Pasi ta provosh, rikthe vlerën:
UPDATE udhetimet SET ora = '08:15' WHERE id = '2';

Përdor vetëm databazën tënde të laboratorit dhe të dhëna fiktive. Fsheh .env.local dhe Connection string nga projektori. Nëse lidhja nuk punon, mos e paraqit një simulim si provë të databazës.
