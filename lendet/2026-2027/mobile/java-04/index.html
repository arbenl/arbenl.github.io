Ushtrimet · hap pas hapi

1. Përgatitu

Hape projektin dhe kontrollo punën e javës së kaluar. Përdor të dhëna fiktive.

2. Ndërto

  1. Vazhdo të njëjtin projekt. Vizato tabelën e udhëtimeve: id, nisja, ora, vendet dhe pronari.
  2. Krijo tabelën në bazën e zgjedhur në ligjëratë dhe shto tri udhëtime fiktive.
  3. Lexoji udhëtimet nga serveri dhe shfaqi në listën ekzistuese.
  4. Shfaq mesazh kur lista është bosh ose lidhja me bazën dështon. Ruaj çelësat vetëm në variabla të mjedisit.

3. Provoje me një koleg

  1. Rifreskimi i faqes i lexon të dhënat nga baza.
  2. Në mungesë të të dhënave shfaqet mesazh i kuptueshëm.
  3. GitHub nuk përmban .env ose çelësa të bazës.

Shkruaj në raport çfarë prite dhe çfarë ndodhi realisht. Nëse prova dështon, shënoje.

4. Dorëzo para se të largohesh

  1. Ruaj kodin dhe raportin java-04.md pranë README në GitHub.
  2. Hap formularin, zgjidh Java 4 dhe vendos linkun e repository-t.
  3. Lexo kontrollin automatik. Pas korrigjimit, komento rikontrollo te i njëjti dorëzim.
