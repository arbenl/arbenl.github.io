# Dorëzimi Mobile — RideShare

Semestri ka **15 javë dhe 15 dorëzime javore**. Prej tyre, **10 ushtrime vlerësohen me deri në 3 pikë secila** (30 pikë laboratori): javët 2–6, 8–10, 12 dhe 14. Javët 1, 7, 11, 13 dhe 15 dorëzohen për feedback dhe evidencë progresi, pa pikë shtesë laboratori. Projekti individual dhe demoja vlerësohen veçmas.

1. Krijo një repository personal rideshare-mobile në llogarinë tënde GitHub: Public + Add README. Nëse ke një repository personal, përdor atë gjatë gjithë semestrit.
2. Ngarko dokumentet në faqen kryesore me Add file → Upload files → Commit changes. Java 1: exit-ticket.md dhe prd.md (pranohen edhe PDF, DOCX, TXT). Java 2: java-02.md dhe skica.jpg/png.
3. Hap formularin, zgjidh javën dhe vendos linkun kryesor të repository-t. Kliko Create / Submit new issue. Lexo raportin automatik poshtë dorëzimit.

Udhëzimi: https://arbenl.github.io/lendet/2026-2027/mobile/dorezimet.html
Formulari: https://github.com/arbenl/arbenl-mobile-assignments-2025/issues/new?template=mobile-submission.yml

Pas korrigjimit të dokumenteve, komento rikontrollo në të njëjtin dorëzim. Mos hap tjetër për të njëjtën javë. Kontrolli teknik nuk është notë. Mos publiko të dhëna personale ose sekrete. Repository privat kërkon dorëzim të asistuar; vetëm ftimi i profesorit nuk aktivizon kontrollin automatik.
