HARTA E APLIKACIONIT · 04 / 13

Ku jeton kodi? Ku jetojnë të dhënat?

Nëse ndryshon ora në Neon, a duhet Push në GitHub? Parashiko para përgjigjes.

Jo. Push nevojitet për ndryshimet e kodit. Ndryshimi i një rreshti në Neon lexohet kur aplikacioni e pyet databazën përsëri.

10–25 MIN · 05 / 13

2. Krijo Neon në projektin Vercel

Ku: projekti yt → Storage / Marketplace → Neon.

Bëj: zgjidh Free, krijo databazën dhe Connect Project.

Kontrollo: DATABASE_URL ekziston në Environment Variables.

Hap Neon Console → SQL Editor. Përdor të njëjtën degë/databazë gjatë orës.

Hap konfigurimin me hapa ↗

Burime zyrtareneon.com · vercel.com

25–35 MIN · 06 / 13

3. Krijo tri udhëtimet

Ku: Neon SQL Editor dhe schema.sql pranë package.json.

Bëj: kopjo SQL-në e udhëzimit dhe kliko Run.

Kontrollo: ID 1, 2 dhe 3 shfaqen; ID 3 ka zero vende.

Ruaj schema.sql edhe në projekt, që ta dorëzosh.

Nëse e ekzekuton dy herë, mbeten tri udhëtime: PRIMARY KEY dhe ON CONFLICT parandalojnë kopjet. Provoje dhe numëro rreshtat.

Hap SQL-në për kopjim ↗

35–55 MIN · 07 / 13

4A. Vendos lidhjen private lokalisht

Ndal serverin me Ctrl+C. Instalo dy paketat më poshtë.

Krijo .env.local pranë package.json; ngjit Connection string si DATABASE_URL.

Kontrollo .gitignore: .env* duhet të jetë i përjashtuar. Sekreti nuk shkon në GitHub.

npm install @neondatabase/serverless server-only

Hap konfigurimin lokal ↗

55–70 MIN · PROVA 1 · 09 / 13

5A. Provo ndryshimin e orës

Para Run: kolegu parashikon cilat ekrane do të ndryshojnë.

Ndrysho vetëm ID 2 në 08:25. Rifresko listën dhe detajet: të dyja duhet të tregojnë 08:25.

Shkruaj rezultatin real te Prova 1. Rikthe 08:15 dhe provo përsëri.

UPDATE udhetimet SET ora = '08:25' WHERE id = '2';

Ndryshon vetëm udhëtimi 2, në të dy ekranet. Nëse njëri mbetet 08:15, kontrollo helper-in, await dhe rifreskimin.

Hap tri provat ↗

55–70 MIN · PROVAT 2–3 · 10 / 13

5B. Provo boshllëkun dhe gabimin

Ndërroni rolet. Njëri përgatit provën, tjetri parashikon mesazhin.

Prova 2: WHERE false → listë bosh. Hiqe kushtin.

Prova 3: riemërto DATABASE_URL dhe rinis → gabim lidhjeje. Rikthe emrin dhe rinis.
