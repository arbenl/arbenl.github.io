Hapi B

B · Lista në një adresë publike · 18–28 min

Skedari: src/app/api/udhetimet/route.ts

Çfarë bën ky kod?

GET /api/udhetimet përdor lexoUdhetimet() të Javës 4 dhe kthen JSON (JavaScript Object Notation) me gjashtë fushat publike. Nuk dërgon profile, email ose sekrete. Në gabim kthen një mesazh të përgjithshëm.

Krijo dosjet api/udhetimet dhe skedarin route.ts. Ky është API (Application Programming Interface – ndërfaqe programimi e aplikacionit). Përdor të njëjtin Neon që ke; nuk krijon databazë tjetër.

import { lexoUdhetimet } from "@/lib/udhetimet";

export const dynamic = "force-dynamic";

// Vetëm të dhënat publike të udhëtimit. Asnjë profil, email ose sesion.
export async function GET() {
  try {
    const rows = await lexoUdhetimet();
    const trips = rows.map(({ id, nisja, destinacioni, ora, vendtakimi, vende }) =>
      ({ id, nisja, destinacioni, ora, vendtakimi, vende }));
    return Response.json({ trips }, { headers: { "Cache-Control": "no-store" } });
  } catch {
    return Response.json({ error: "Lista nuk mund të lexohet tani." }, { status: 503 });
  }
}

Kontrollo: Hap /api/udhetimet. Duhet të shohësh trips me tri udhëtime, pa kredenciale.

Hapi C

C · Service worker dhe kopja lokale · 28–40 min

Skedari: public/sw.js

Çfarë bën ky kod?

Install ruan dokumentin offline dhe ikonat. Activate pastron vetëm cache-t e vjetra të këtij shembulli. GET i listës provon serverin dhe ruan përgjigjen e mirë me kohë. Në dështim lexon kopjen; POST, paneli dhe hyrja nuk ruhen.

Krijo sw.js në public/, jo në src/. SHELL është lista e skedarëve të lejuar. Pa offline.html, regjistrimi fillestar nuk përfundon: atë e krijon menjëherë te D.

// Kjo cache përmban VETËM dokumentin offline, ikonat dhe listën publike.
const CACHE = "rideshare-public-v1";
const API = "/api/udhetimet";
const SHELL = ["/offline.html", "/icons/icon-192.png", "/icons/icon-512.png"];

self.addEventListener("install", event => {
  event.waitUntil(caches.open(CACHE).then(cache => cache.addAll(SHELL))
    .then(() => self.skipWaiting()));
});
self.addEventListener("activate", event => {
  event.waitUntil(caches.keys().then(keys => Promise.all(keys
    .filter(key => key.startsWith("rideshare-public-") && key !== CACHE)
    .map(key => caches.delete(key)))).then(() => self.clients.claim()));
});

async function readPublicList(request) {
  const cache = await caches.open(CACHE);
  try {
    const response = await fetch(request);
    if (!response.ok || !response.headers.get("content-type")?.includes("application/json")) {
      throw new Error("Lista nuk erdhi nga serveri");
    }
    const headers = new Headers(response.headers);
    headers.set("x-rideshare-source", "network");
    headers.set("x-rideshare-saved-at", new Date().toISOString());
    const fresh = new Response(await response.text(), { status: 200, headers });
    // Nëse hapësira lokale është plot, lista nga serveri prapë shfaqet.
    try { await cache.put(API, fresh.clone()); } catch {
      // Mos pretendo ruajtje kur pajisja nuk e pranoi kopjen.
      fresh.headers.delete("x-rideshare-saved-at");
    }
    return fresh;
  } catch {
    const saved = await cache.match(API);
    if (!saved) return new Response(JSON.stringify({ error: "no_snapshot" }), {
      status: 503, headers: { "content-type": "application/json" },
    });
    const headers = new Headers(saved.headers);
    headers.set("x-rideshare-source", "cache");
    return new Response(await saved.text(), { status: 200, headers });
  }
}

self.addEventListener("fetch", event => {
  const request = event.request, url = new URL(request.url);
  if (request.method !== "GET" || url.origin !== self.location.origin) return;
  if (url.pathname === API && !url.search) {
    event.respondWith(readPublicList(request));
  } else if (request.mode === "navigate" && ["/", "/offline.html"].includes(url.pathname)) {
    event.respondWith(fetch(request).catch(async () => {
      const saved = await caches.match("/offline.html");
      return saved || new Response("Hape RideShare një herë me internet.", { status: 503 });
    }));
  }
  // /panel, /api/auth, POST dhe faqet private nuk ruhen dhe nuk ridërgohen.
});

Hapi E

E · Regjistro worker-in · 48–52 min

Skedari: src/components/Pwa.tsx

Çfarë bën ky kod?

Ky komponent punon në shfletues. Regjistron /sw.js dhe kërkon listën pasi worker-i kontrollon faqen. Kjo kërkesë mbush kopjen që në vizitën e parë: lista e renderuar në server nuk e bën vetë.

Krijo Pwa.tsx në components/. Përdor localhost në laborator ose HTTPS në Vercel. Një adresë HTTP me IP të rrjetit lokal zakonisht nuk lejon service worker.

"use client";
import { useEffect } from "react";

export default function Pwa() {
  useEffect(() => {
    if (!("serviceWorker" in navigator)) return;
    let cancelled = false;
    // Server rendering nuk mbush cache-n e JSON-it. E kërkojmë një herë këtu.
    async function warmSnapshot() {
      if (cancelled || !navigator.serviceWorker.controller) return;
      try { await fetch("/api/udhetimet", { cache: "no-store" }); } catch { /* offline */ }
    }
    navigator.serviceWorker.addEventListener("controllerchange", warmSnapshot);
    navigator.serviceWorker.register("/sw.js", { scope: "/" })
      .then(() => navigator.serviceWorker.ready).then(warmSnapshot).catch(() => {});
    return () => {
      cancelled = true;
      navigator.serviceWorker.removeEventListener("controllerchange", warmSnapshot);
    };
  }, []);
  return <aside style={{ padding: "1rem" }}>
    <a href="/offline.html">Lista për lexim pa internet</a>
    <p>Kopja e ruajtur mund të jetë e vjetër. Këtu nuk konfirmohen rezervime.</p>
  </aside>;
}

2. Tri prova me një koleg · 55–63 min

Njëri vepron, tjetri parashikon dhe lexon mesazhin. Ndërroni rolet. Në Chrome/Edge: Inspect → ikona telefon/tablet → 375 px. Përdor Network → Offline vetëm në tab-in RideShare, që tab-i i Neon të mbetet online.

Prova 1 · Manifesti dhe vizita online

  1. Hap /manifest.webmanifest dhe dy ikonat. Emri: RideShare AAB; përmasat 192×192 dhe 512×512.
  2. Hap faqen kryesore me internet. Te Application → Service Workers kontrollo që /sw.js është aktiv.
  3. Te Cache Storage → rideshare-public-v1 gjej /api/udhetimet; hap /offline.html dhe lexo listën dhe kohën.

Instalimi në telefon është opsional nëse shfletuesi e ofron. Në iPhone zakonisht përdoret Share → Add to Home Screen; në Chrome/Edge menyja e instalimit. Nëse mungon, shënoje; vazhdo provën në shfletues.

Prova 2 · Pa internet, edhe pas rifreskimit

  1. Te tab-i RideShare aktivizo Network → Offline.
  2. Hap / dhe rifresko faqen. Dokumenti offline duhet të shfaqë tri karta dhe kohën e kopjes.
  3. Lexo mesazhin e të dhënave të ruajtura. Butoni Kërko vend është i çaktivizuar; nuk ka rezervim të konfirmuar.

Pse kjo provë? Pamja që mbetet në një tab të hapur nuk provon offline. Rifreskimi provon që dokumenti dhe lista mund të lexohen pa rrjet.

Prova 3 · Rikthe lidhjen dhe kërko të dhënat e reja

  1. Mbaje RideShare offline. Në tab-in online të Neon → SQL Editor ndrysho orën e ID 2:
UPDATE udhetimet SET ora = '08:25' WHERE id = '2';

Ky SQL (Structured Query Language – gjuha e pyetjeve të strukturuara) ndryshon vetëm orën e udhëtimit 2 në databazën tënde. Kopja offline ende tregon 08:15.

  1. Te RideShare zgjidh Network → No throttling/Online. Kliko Rifresko listën.
  2. ID 2 duhet të tregojë 08:25, burimin server dhe kohën e re. Vetëm rikthimi i ikonës së rrjetit nuk mjafton.
  3. Në Neon rikthe 08:15 me të njëjtin UPDATE dhe rifresko sërish.

Kur ka dështim: shëno rezultatin real në raport dhe kërko ndihmë; mos shkruaj se prova kaloi nëse nuk e pe.

Dorëzo punën · Java 6 Si dorëzoj? · 3 hapa

5/5 është kontroll teknik, jo notë. Bot-i nuk ekzekuton kod, nuk hap Neon dhe nuk përdor AI. Java 6 ka deri në 3 pikë sipas rubrikës së lëndës. Nëse përgjigjja vonon, mos krijo Issue tjetër: ruaj numrin dhe njofto profesorin para se të largohesh.

Ndihmë kur diçka nuk punon
  • Worker nuk aktivizohet: /offline.html dhe dy ikonat duhet të hapen; kontrollo që public/ është pranë package.json. Përdor localhost ose HTTPS.
  • Worker i vjetër: Application → Service Workers → Update. Nëse duhet, Unregister vetëm në localhost të projektit tënd; fshi vetëm cache-n rideshare-public-v1 dhe hape sërish online.
  • Lista nuk ruhet: hape fillimisht me internet dhe kontrollo /api/udhetimet. Pas kontrollit nga worker-i, Pwa.tsx e kërkon listën posaçërisht për kopjen.
  • Vizitë e parë pa kopje: është normale të shfaqet “Ende nuk ka listë të ruajtur”. Cache mund të fshihet nga shfletuesi; nuk është backup i databazës.
  • Serveri/Neon nuk përgjigjet: mund të lexohet kopja e fundit me paralajmërim. Mos shfaq sukses të rremë.
Sfidë shtesë pas dorëzimit

Në një profil të ri të shfletuesit, provo rastin pa kopje. Shpjego mesazhin. Pastaj përshtate emrin dhe ikonat për biznesin tënd, duke mbajtur të njëjtat kufij të privatësisë.
