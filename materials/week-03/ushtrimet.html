Nëse përdor AI gjatë orës

Jepi java-02.md dhe përshkrimin e skicës, pa të dhëna personale. Kërko ndihmë për tri faqet e Javës 3; mbaj kontrollin e çdo skedari dhe provo rezultatin vetë.

Kam skicën e RideShare për listën, detajet dhe kërkesën. Më ndihmo
t'i ndërtoj në Next.js me App Router, vetëm me të dhëna fiktive.
Përdor një komponent karte dhe adresën /udhetimi/[id].

Nëse nuk ke qasje në AI, ndiq kodin e shembullit më poshtë. Dorëzimi dhe pesë kontrollet janë të njëjta për të gjithë.

  1. java-03.md pranë README, i plotësuar.

Kodi i shembullit, një skedar në çdo hap

Ky është një model mësimor. Mund t’i ndryshosh emrat dhe vendet me të dhëna fiktive. Nëse projekti yt nuk përdor dosjen src, krijo skedarët përkatës në app, components dhe lib në rrënjë. Shembulli përdor aliasin standard @/ të projektit të krijuar me udhëzimin tonë.

Hapi A · të dhënat e njëjta për të gjitha faqet

Krijo src/lib/udhetimet.ts. ID-ja mbetet e njëjtë edhe kur ndryshon renditja e listës.

export type Udhetim = {
  id: string;
  nisja: string;
  destinacioni: string;
  ora: string;
  vendtakimi: string;
  vende: number;
};

export const udhetimet: Udhetim[] = [
  { id: "1", nisja: "Prishtinë", destinacioni: "AAB", ora: "08:00",
    vendtakimi: "Stacioni i autobusëve", vende: 2 },
  { id: "2", nisja: "Fushë Kosovë", destinacioni: "AAB", ora: "08:15",
    vendtakimi: "Te stacioni kryesor", vende: 1 },
  { id: "3", nisja: "Lipjan", destinacioni: "AAB", ora: "07:45",
    vendtakimi: "Qendra e qytetit", vende: 0 },
];

export function gjejUdhetimin(id: string) {
  return udhetimet.find((udhetim) => udhetim.id === id);
}

Hapi D · detajet e udhëtimit të zgjedhur

Krijo dosjet dhe skedarin src/app/udhetimi/[id]/page.tsx. Kllapat në emrin e dosjes janë pjesë e App Router.

import Link from "next/link";
import { notFound } from "next/navigation";
import { gjejUdhetimin } from "@/lib/udhetimet";

export default async function Detajet({
  params,
}: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const udhetim = gjejUdhetimin(id);
  if (!udhetim) notFound();

  return (
    <main>
      <Link href="/">← Kthehu te lista</Link>
      <h1>{udhetim.nisja} – {udhetim.destinacioni}</h1>
      <p>Ora: {udhetim.ora}</p>
      <p>Vendtakimi: {udhetim.vendtakimi}</p>
      <p>Vende të lira: {udhetim.vende}</p>
      {udhetim.vende > 0 ? (
        <Link className="action" href={`/udhetimi/${id}/kerkesa`}>
          Kërko vend
        </Link>
      ) : <p>Nuk ka vende të lira.</p>}
    </main>
  );
}

Hapi E · kërkesa është vetëm demonstrim

Krijo src/app/udhetimi/[id]/kerkesa/page.tsx. Ky ekran nuk ruan asgjë në server.

import Link from "next/link";
import { notFound } from "next/navigation";
import { gjejUdhetimin } from "@/lib/udhetimet";

export default async function Kerkesa({
  params,
}: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const udhetim = gjejUdhetimin(id);
  if (!udhetim) notFound();

  return (
    <main>
      <Link href={`/udhetimi/${id}`}>← Kthehu te detajet</Link>
      {udhetim.vende > 0 ? (
        <>
          <h1>Simulim: Në pritje</h1>
          <p>Kërkesa për {udhetim.nisja} nuk është dërguar te shoferi.</p>
          <p>Ruajtjen dhe konfirmimin real do t’i shtojmë më vonë.</p>
        </>
      ) : <h1>Nuk ka vende të lira.</h1>}
    </main>
  );
}
